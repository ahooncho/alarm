# 요구사항

## 배경

- POSTECH 기숙사 2인실에서 생활해요. 매일 6시에 일어나요.
- 이른 알람으로 룸메이트를 깨우지 않는 게 가장 중요해요.
- 기기는 Galaxy S24(Android 14 이상, One UI)와 AirPods Pro 2예요.
- 쓰던 이어폰 알람 앱이 유료로 바뀌어서 직접 만들어요. 나만 쓰고 Play 스토어에는 올리지 않아요.

## 필수

| 항목 | 결정 |
| --- | --- |
| 소리 출력 | 이어폰에서만 울려요. 폰 스피커로는 어떤 경우에도 소리를 내지 않아요. |
| 이어폰이 없거나 중간에 끊길 때 | 폰 진동만 해요. 이어폰이 다시 연결되면 이어폰으로 이어서 울려요. |
| AirPods 줄기 누르기 | 아무 동작도 하지 않아요. 실수로 누르는 일이 많아서예요. |
| 디자인 | 미니멀리즘·모더니즘에 입각한 흑백. 색 없이 검정·흰색·회색만 써요. 모서리는 각지게 해요. |

## 기본값 (앱에서 바꿀 수 있음)

| 설정 | 기본값 |
| --- | --- |
| 이어폰 볼륨 | 미디어 최대 볼륨의 40%. 알람이 끝나면 원래 볼륨으로 되돌려요. |
| 점점 크게 | 30초 |
| 스누즈 | 5분 |
| 자동 종료 | 15분 |

## 알려진 한계

- 방해 금지 모드에서 미디어 소리를 막으면 알람 소리도 막혀요. 앱의 상태 항목에서 확인할 수 있어요.
- AirPods가 귀에서 빠졌지만 연결이 유지된 상태는 감지하지 못해요.
- 블루투스 스피커도 이어폰과 같은 종류의 장치로 보여서 구분하지 못해요.
- 시스템 알람음이 내 파일(외부 저장소)에 있으면 읽지 못할 수 있어요. 그때는 앱에 내장된 소리를 써요.
